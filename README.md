# AI Voice Assistant

An AI voice assistant named Ava that runs assessment conversations with
customers, including financial assessment, business management assessment,
health and wellness assessment, sales assessment, and a general needs
assessment. Ava is powered by the Google Gemini API, speaks and listens
through the browser, and produces a written report at the end of each
conversation.

This project is intended as a demonstration piece for an AI engineering
role. It shows a working, end to end product: prompt design for a
consistent human sounding persona, multimodal input handling (voice and
text), and a simple deployable interface.

## Project structure

```
ai_voice_assessment_assistant/
├── app.py                        Main Streamlit application
├── gemini_client.py               Wrapper around the Gemini API
├── assessments.py                 Assessment definitions and prompts
├── voice_utils.py                 Text to speech playback helper
├── requirements.txt                Python dependencies
├── .streamlit/
│   └── secrets.toml.example       Template for your API key
├── .gitignore
└── README.md
```

## How it works

1. The customer picks an assessment type in the sidebar and presses Start.
2. Ava opens the conversation and asks questions one at a time, the same
   way a human consultant would, adapting to what the customer says.
3. The customer can answer either by recording their voice with the
   built in microphone recorder, or by typing.
4. Recorded audio is sent directly to Gemini, which transcribes it, since
   Gemini understands audio natively and no separate speech recognition
   library is required.
5. Ava's text reply is generated by Gemini using a system prompt that is
   specific to the chosen assessment type, and is also converted to
   speech with gTTS so it can be played back in the browser.
6. When the conversation has covered enough ground, the customer presses
   Generate final report, and Gemini turns the full transcript into a
   structured written report that can be downloaded as a text file.

## Prerequisites

- Python 3.10 or newer
- A Google Gemini API key
- Visual Studio Code, or any code editor of your choice

## Notes on responsible use

Ava is designed to give general information and structured observations,
not licensed professional advice. The financial, business, sales, and
wellness reports it produces are meant as a helpful starting point for a
conversation with a qualified professional, not a replacement for one.
This is reflected directly in the system prompts in `assessments.py`.
