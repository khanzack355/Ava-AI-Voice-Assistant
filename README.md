# AI Voice Assessment Assistant

An AI voice assistant named Ava that runs assessment conversations with
customers, including financial assessment, business management assessment,
health and wellness assessment, sales assessment, and a general needs
assessment. Ava is powered by the Google Gemini API, speaks and listens
through the browser, and produces a written report at the end of each
conversation.

This project is intended as a demonstration piece for an AI engineering
role. It shows a working, end to end product: prompt design for a
consistent human sounding persona, multimodal input handling (voice and
text), and a simple deployable interface.

## Project structure

```
ai_voice_assessment_assistant/
├── app.py                        Main Streamlit application
├── gemini_client.py               Wrapper around the Gemini API
├── assessments.py                 Assessment definitions and prompts
├── voice_utils.py                 Text to speech playback helper
├── requirements.txt                Python dependencies
├── .streamlit/
│   └── secrets.toml.example       Template for your API key
├── .gitignore
└── README.md
```

## How it works

1. The customer picks an assessment type in the sidebar and presses Start.
2. Ava opens the conversation and asks questions one at a time, the same
   way a human consultant would, adapting to what the customer says.
3. The customer can answer either by recording their voice with the
   built in microphone recorder, or by typing.
4. Recorded audio is sent directly to Gemini, which transcribes it, since
   Gemini understands audio natively and no separate speech recognition
   library is required.
5. Ava's text reply is generated by Gemini using a system prompt that is
   specific to the chosen assessment type, and is also converted to
   speech with gTTS so it can be played back in the browser.
6. When the conversation has covered enough ground, the customer presses
   Generate final report, and Gemini turns the full transcript into a
   structured written report that can be downloaded as a text file.

## Prerequisites

- Python 3.10 or newer
- A Google Gemini API key, created at https://aistudio.google.com/apikey
- Visual Studio Code, or any code editor of your choice

## Setup in VS Code

1. Open the `ai_voice_assessment_assistant` folder in VS Code.

2. Open a terminal inside VS Code (Terminal, then New Terminal) and create
   a virtual environment:

   ```
   python -m venv venv
   ```

3. Activate the virtual environment:

   On Windows:
   ```
   venv\Scripts\activate
   ```

   On macOS or Linux:
   ```
   source venv/bin/activate
   ```

4. Install the dependencies:

   ```
   pip install -r requirements.txt
   ```

5. Set up your API key. Copy the example secrets file:

   ```
   cp .streamlit/secrets.toml.example .streamlit/secrets.toml
   ```

   Then open `.streamlit/secrets.toml` in VS Code and paste your real
   Gemini API key in place of the placeholder text.

6. In VS Code, select the virtual environment as your Python interpreter:
   open the command palette (Ctrl+Shift+P or Cmd+Shift+P), choose
   "Python: Select Interpreter", and pick the one inside the `venv` folder.

## Running the app locally

From the project folder, with the virtual environment activated:

```
streamlit run app.py
```

Streamlit will open the app in your browser, normally at
http://localhost:8501. Your browser will ask for microphone permission the
first time you try to record an answer; allow it to use the voice input
feature.

## Deploying with Streamlit Community Cloud

1. Push this project to a GitHub repository. Make sure `.streamlit/secrets.toml`
   is not included, since it is already listed in `.gitignore`.

2. Go to https://share.streamlit.io and sign in with your GitHub account.

3. Choose New app, select your repository, and set `app.py` as the main
   file.

4. Before deploying, open the app's Settings, then Secrets, and paste in:

   ```
   GEMINI_API_KEY = "your-real-api-key"
   ```

5. Press Deploy. Streamlit will install everything from `requirements.txt`
   automatically and give you a public link to the running app.

## Customizing or extending the project

- To add a new assessment type, add a new entry to the `ASSESSMENTS`
  dictionary in `assessments.py` with a title, description, system_prompt,
  and report_prompt, following the same pattern as the existing ones.
- To change Ava's voice language, pass a different `lang` value to
  `text_to_speech` in `voice_utils.py`, for example `lang="hi"` for Hindi.
- To change the Gemini model being used, edit `DEFAULT_MODEL` at the top
  of `gemini_client.py`.

## Notes on responsible use

Ava is designed to give general information and structured observations,
not licensed professional advice. The financial, business, sales, and
wellness reports it produces are meant as a helpful starting point for a
conversation with a qualified professional, not a replacement for one.
This is reflected directly in the system prompts in `assessments.py`.
